`stretch take attempt 1: output take must differ from its source`.

`got 1 attempts, want 2`.
The unmutated suite passes all 23 tests in 10.72 s.

**2. Limits validation pin.**
I verified that `NewRepairer` and `RepairLine` reject invalid non-zero limits.
I passed `{0.25, 0.25}`, `{-0.05, 0.08}`, `{0.05, -0.08}`, `{0.05, 0.20}`, and `{0.0, 0.08}`.
Both functions returned errors satisfying `errors.Is(err, ErrLimits)`.
Calling `NewRepairer` with zero-value `StretchLimits{}` defaulted cleanly to `{Short: 0.05, Long: 0.08}`.
Mutating the check to allow invalid limits caused `TestStretchLimitsValidation` to fail with exit code 1.

**3. Direct signed delta derivation.**
`SignedDeltas()` and `SignedDeltaMs()` derive signed delta from `a.Fit.Measured - a.Fit.Slot`.
`TestSignedDeltasDerived` creates attempts with explicit `Delta: 0` and timing misfits of +500ms and -300ms.
`SignedDeltas()` returns `[500ms, -300ms]`.
`SignedDeltaMs()` returns `[500, -300]`.
Mutating both functions to read `a.Fit.Delta` failed `TestSignedDeltasDerived` with exit code 1.
