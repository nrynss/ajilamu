## What I did not file

The frontend build gap belongs to T7.0a, which is written and not-started. The shipped binary
answers `GET /` with 503 until the static adapter lands.

The injected callback in the real `main.go` always fails, so the shipped endpoint answers 500
for a well-formed save. T7.4a owns durable persistence, so I treated that as scaffolding.

The live `main.go` mounts the snapshot constructor. The handoff records this as T7.0's remaining
wiring. The provider API exists and works, so I filed no residue against T7.4.

A project served with `"languages": null` crashes the index render and leaves the loading state
up. I observed this when my harness sent an incomplete payload. No current producer emits it.
The fixture carries languages, and the upload handler rejects a request without one. I record it
as an observation, not a finding.

`go test ./internal/media` stays red on missing fixtures. That predates this seam.
