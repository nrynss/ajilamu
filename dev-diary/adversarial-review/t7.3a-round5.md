## What I did not file

- **The unrecorded-take collision.** A line interrupted mid-attempt leaves a take with no
  record. The next pass re-renders to the same path and the production synthesizer refuses to
  overwrite. Rounds 1 to 4 measured and declined it. The Done-when scopes interruption to after
  a completed take.
- **The mismatch collision with a refusing synthesizer.** A record for another language or
  another segment is ignored, but its take stays at the render path. Round 4 declined it as the
  pre-existing overwrite refusal.
- **A flagged record whose chosen take is corrupt.** The loop discards the chosen take and
  re-renders. The earlier attempt files can still block the fresh render. This is the same
  pre-existing overwrite refusal, and it needs a corrupt chosen take plus several attempts.
- **The resumed run reports zero cost for replayed lines.** Rounds 1 to 3 declined it. The
  ledger holds the first run's charges, so the project counts each segment once.
- **The redundant size check.** Mutation M1 survives because the probe rejects empty files.
  The check is redundant, not wrong.
- **The language check has no shipped test.** Mutation M5 dies only on my pin. This is a
  coverage observation, not a defect.
- **The probe doubles the ffprobe calls on a resume.** Round 3 measured two spawns per resumed
  take. This is a performance observation, not a defect.
- **The record files in the work directory.** I checked the consumers. `assembleRun` builds
  clips from `result.Lines`, and `internal/api/run.go` globs the dub directory rather than the
  work directory. The `seg_<id>_result.json` files reach no mix and no ledger row.
