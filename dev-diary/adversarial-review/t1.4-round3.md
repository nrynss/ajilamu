## What I did not file

- **The five missing `testdata/wire/` payloads belong to T1.4a.** T1.4 owns only `wire.go` and
  `types.ts`. T1.4a owns `testdata/wire/` and `wire_test.go`, and it requires T7.2c, which is
  done. The split keeps the implementation inside its owned paths. T1.4a is the right home.
- **`mirroredTypes` stays a manual list.** Its second comment sentence claims the guard fails
  when a struct lands on one side only. That is true only for a listed struct. The list is
  complete today, so no drift hides now. The text predates this patch and rounds 1 and 2 accepted
  it. I file no defect. The author may want a derived list later.
- **`TimelineEntry.VersionSeq` is `uint64` in Go and `number` in TypeScript.** A value above
  2^53 loses precision. A real sequence stays far below 2^53. Round 2 considered this and filed
  no defect.
- **`BranchSummary.AttributedCostUSD` is a decimal string.** The `types.ts` header says money is
  always an exact nanodollar integer. T7.2c chose the string on purpose and documents the field.
  Round 2 considered this and filed no defect.
- **Go enum fields are `string` while TypeScript uses a union.** `Readiness`, `FitState`,
  `RepairKind`, `ChargeKind`, `CommitAuthor`, `CommitAction`, `EventType`, and `EventStage`
  follow this shape. Round 1 accepted it and the patch did not touch it.
- **T1.4 carries `status: done` while five examples are missing.** The done condition says
  `testdata/` holds an example for each structure. Round 2 recorded the gap and the orchestrator
  wrote T1.4a for it. The README now shows P1 at 5 / 6. I treat the split as the remedy.
- **Active voice.** My scan found copular clauses and subordinate passives. `Emotion describes
  how the line is spoken` carries an active main clause. `DeltaMs is measured minus slot` reads
  as a copular predicate. I filed no style defect.
