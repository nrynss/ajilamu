# T6.3 Contract Change Proposal

## Status

T6.3 can edit the target line and re-render it inside its owned paths. T6.3 cannot
re-translate a corrected source line. The landed re-render route accepts a target
text only.

`Text.svelte` edits both fields and prompts before each billable action. The source
prompt reports the gap rather than inventing an endpoint. `confirmSource` sends
nothing and calls no model.

## Verified Assertions

| Assertion | Result | Evidence |
|---|---|---|
| I own every implementation path. | Pass | T6.3 owns `web/src/lib/edit/Text.svelte` and `web/src/routes/d/[id]/+page.svelte`. |
| The target-text shapes exist. | Pass | `POST /api/dubs/{id}/lines/{segment}/rerender` takes `language`, `text` and `speaker`. A supplied `text` is authoritative, so the fit loop calls no translation model. |
| I can re-translate a corrected source line. | Fail | The route body carries no source-text field. No handler writes a corrected source line. |
| The ledger accepts the change. | Pass | `api.ActionTextCorrected` exists in `internal/api/wire.go`, and `internal/ledger/actions.go` accepts it under `manual_ui`. |

## Required Contract Change

Add one source-text path. Either field works, and the owner chooses one:

- Add an optional `source_text` field to the existing re-render route body.
- Add a sibling route that re-translates one line from a corrected source.

The path must do all of this:

1. Set the segment text from the corrected source before the fit loop runs.
2. Run the translation model, because no authoritative target text exists yet.
3. Run the fit loop on the translated line and save a new take beside the old ones.
4. Record the take, its charges, one commit and one timeline snapshot.
5. Name the commit action `text_corrected` with author `manual_ui`.
6. Answer a shape the page can apply, including the new take and its charges.

The route owner must also add a test that proves the translation model runs on this
path and that the target-text path still calls it zero times.

## Ownership

`internal/api/rerender.go`, `internal/api/rerender_test.go`, `internal/api/server.go`
and `cmd/ajilamu/main.go` belong to T6.5a, which is done. A new task or an
orchestrator amendment must own the change. T6.3 does not reach outside its seam.

## Boundary

This record changes no code, no route and no test. It names the missing path and
stops there.
