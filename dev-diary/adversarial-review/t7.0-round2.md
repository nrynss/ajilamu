**Finding 2, resolved.** I built `./cmd/ajilamu` to a temporary path and ran it under
`env -i` with only `PATH`, `HOME`, and `PORT=46321`. I sent SIGINT to the child process
itself. Exit code 0, and stderr held no `ledger client is nil` line. SIGTERM on port
46322 gave the same result. No `go run` wrapper sat between the signal and the server.

**Finding 3, resolved.** I ran the binary with `AJILAMU_DATA_DIR` pointed at a temporary
directory on port 46323. A multipart POST of video plus music to `/api/dubs/new` returned
201 with `application/json`. The response carried project-relative paths. Both files sat
on disk under `uploads/<id>/` at mode 0600. Their SHA-256 digests matched the bytes I
sent.
