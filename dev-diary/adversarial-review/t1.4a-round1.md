  `segment.json`, and the suite stayed green. My external token walk found zero duplicate keys
  across all 17 files. The test claims tag matching, not duplicate detection, and the spec says
  keep each key identical to its Go tag. I file no defect.

  Version 7 names a parent that the list omits. The `DubHistory.Commits` doc says every commit,
  oldest first. No test or consumer reads the chain, so no code path breaks. I file no defect. The
  fixture does not exercise a full chain.
