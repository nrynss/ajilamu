### Ordering and determinism, measured

A probe built four rows with a `version_seq` tie and shuffled them 500 times. Every run returned
`(version_seq, commit_id)` order `d0, d1, d2, d3`. The shipped test repeats ten times clean. Map
iteration cannot leak into the result because `collapseCommitHistory` sorts on a total order.

### Collapse rule, measured

I measured each precedence step alone. A prompt-bearing row beat a newer row with no prompt. The
greatest `action_created_at_ms` won among equal prompt presence. The greatest `event_key` won on a
timestamp tie. A commit with no action kept empty action, author and instruction and did not
borrow the `agent` Enum8 default. A commit with two actions collapsed to one row.

### created_at, measured

`time.UnixMilli(ms).UTC().Format(time.RFC3339Nano)` is absolute. The shipped test pins
`2026-09-08T00:00:00Z`, `2026-09-08T00:00:01.5Z`, and `2026-09-08T00:00:02.789Z`. A zero
millisecond value yields `1970-01-01T00:00:00Z`, which is valid RFC 3339. `commits_raw.created_at`
defaults to `now64(3)`, so a shipped writer never stores zero. `wire.Commit.CreatedAt` is a string,
so it carries the value.

### Parameter binding and the T7.2a pin, measured

`selectCommitHistory` binds `{dub_id:String}` in both subqueries. The captured query carried
`param_dub_id=dub-history` and did not contain the dub id. `ListCommits` calls `queryClickHouse`,
names neither pinned setting, and is driven by the extended
`TestClickHouseReadersSurviveQuotedIntegers`. `TestOnlyClientPinsServerSettings` still passes.

### Branch cost measurement and decision

I searched every INSERT into `charges_raw` in the repository. One writer exists. `chargeInsert` in
`internal/ledger/takes.go:19` is used only by `RecordTake` at `takes.go:93`. `TakeAttempt.rows()`
rejects an empty `CommitID` at `takes.go:123`, and `chargeRows()` copies `a.CommitID` into every
charge row at `takes.go:208`. `cost.Charge` in `internal/cost/cost.go:76` carries no commit field.
`internal/gemini/segment.go` and `internal/tts/chirp.go` build a `cost.Charge` without a commit, and
those charges reach `charges_raw` only through `RecordTake`, which stamps the attempt commit. So no
shipped writer can produce an unattributed charge. The rename to `AttributedCostUSD` is the honest
fix and it is complete in Go. The only remaining `CostUSD` in `internal/` is the unexported
`branchCostRow.CostUSD` decode alias at `history.go:100`, which the task leaves unchanged.

  fractional zeros. It is a valid RFC 3339 profile and the wire field is a string, so I did not
  file it.

  task adds only the read.
