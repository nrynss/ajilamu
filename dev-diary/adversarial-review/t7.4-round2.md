## Scope and Evidence

I reviewed the T7.4 task block, the T7.4 handoff contract, `dev-diary/README.md`, `ui-ux.md`
sections 8 through 10, the round-one review, the round-one remediation, and the four owned
files. I changed no implementation, test, Svelte, or review file. I ran every probe from
scratch copies outside the worktree.

### The harness

I copied the worktree to `/tmp/t74rev` and `/tmp/t74mut`. Both sit outside the repository and
outside every other worktree. Every patch below applied to a copy.

The shipped `web/svelte.config.js` uses `adapter-auto`. Running `npm --prefix web run build`
emits `.svelte-kit/output` and no `web/build`, so the compiled binary answers `GET /` with
`503 Frontend build is unavailable. Run npm --prefix web run build.` **T7.0a already owns that
gap and remains not-started, so I file no T7.4 finding for it.** To reach the pages at all I
installed `@sveltejs/adapter-static` in the copy and built a real `web/build`. Every browser
measurement below ran against the compiled Go binary serving that production bundle.

I patched only `cmd/ajilamu/main.go` in the copy, which T7.0 owns and T7.4 does not. Two
changes went in. The configuration callback appends its received values to a file and returns
`nil`, which gives me a real `204` and a witness for callback invocation. A `REVIEW_INDEX`
environment variable selects the index payload, which lets me measure ordering, an empty list,
and mixed readiness values.

I drove headless Chrome over the DevTools Protocol from a plain Node script using the built-in
WebSocket client. No automation library took part. The script also captured every HTTP response
body the page received and searched each one for my marker credentials.

Servers ran on ports 47311, 47312, 47313, and 47314. The debugging endpoint ran on 47399. I
bound nothing to 8080. I stopped every process and confirmed all five ports closed.

### Health checks, not pins

`go test -count=1 ./internal/api` passed. `go test -count=1 ./internal/config` passed.
`npm --prefix web run check` reported zero errors and zero warnings. `go vet` on
`./internal/api` and `./cmd/ajilamu` printed nothing. Neither owned Svelte file contains
`export let`, a `$:` label, or a store import. None of this is a pin.
