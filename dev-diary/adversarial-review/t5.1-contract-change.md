# T5.1 Contract Change Proposal

## Status

T5.1 is blocked before implementation. The task owns three source files but requires an absent SvelteKit and Vite bootstrap.

## Verified Assertions

| Assertion | Result | Evidence |
|---|---|---|
| I own every implementation path. | Pass | The task owns `web/src/app.html`, `web/src/routes/+layout.svelte`, and `web/src/lib/tokens.css`. |
| The needed data shapes exist. | Pass | `web/src/lib/types.ts` provides the frozen T1.4 wire contract. The T1.5 fixtures provide the matching JSON payloads. |
| I can validate the task on its own. | Fail | `web/` contains only `src/lib/types.ts`. It has no package manifest, SvelteKit adapter, Vite configuration, TypeScript configuration, application entry point, or route entries. |

## Required Contract Change

Add a bootstrap task, or expand T5.1 ownership, to include these paths:

- `web/package.json`
- `web/vite.config.ts`
- `web/svelte.config.js`
- `web/tsconfig.json`
- `web/src/app.d.ts`
- `web/src/routes/+page.svelte`
- `web/src/routes/new/+page.svelte`
- `web/src/routes/d/[id]/+page.svelte`
- `web/src/routes/config/+page.svelte`

The configuration must install Svelte 5, SvelteKit, and Vite. It must define `check` and `build` scripts. Each route entry must render the shared layout child so that the four required URLs resolve.

## Why T5.1 Cannot Absorb This Work

`web/src/app.html` is a SvelteKit template, not Vite's application entry. Without the listed configuration, no command can compile it. `+layout.svelte` does not create route pages. The required routes need files outside T5.1's owned paths.

## Validation Plan After Resolution

1. Run `npm run check` from `web`.
2. Run `npm run build` from `web`.
3. Start the Vite preview server and request `/`, `/new`, `/d/fixture`, and `/config`.
4. Toggle the explicit `data-theme` value and inspect the computed color variables.
5. Check system UI typography, tabular numeric typography, border radii, and the 46px header in both themes.

## Affected Tasks

T5.2, T5.3, T5.4, T5.5, T5.6, P6, and P8 depend on T5.1.
