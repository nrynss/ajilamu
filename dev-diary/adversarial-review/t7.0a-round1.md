## Observations outside T7.0a

These are real, and none of them belongs to this task. I record them so nobody loses them.

**T7.0 owns frontend discovery by working directory.** `findFrontendRoot` resolves the relative
path `web/build`. Running the binary from `/tmp` cannot find it. The process never reaches that
check, because fixture loading fails first with `fixture manifest.json not found`. The binary
therefore only runs from inside the repository tree. That is T7.0's contract, and T7.0a placed
its output exactly where T7.0 looks.

**The web workspace has no lockfile and no engines pin.** `web/package-lock.json` does not
exist, and `web/package.json` declares no `engines` field. The build ran on Node v22.23.1 while
`AGENTS.md` freezes Node 26. Both gaps predate this task and neither path sits in its `owns`
line. The lockfile especially deserves a task of its own, since a build contract that no lock
pins is not reproducible.
