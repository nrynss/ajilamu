## Required Ownership Changes

H2 cannot be fixed inside the T7.2 seam. The workspace route reads `loadFixtureDub`, which ignores the
project id, and no route serves a stored project. A remediator needs either an id-aware workspace or an
honest empty state for a project with no takes. Both live in `web/src/routes/d/[id]/+page.svelte` and
`web/src/lib/fixture.ts`, which T7.2 does not own.

M2 needs a durable pin on the process wiring. `cmd/ajilamu` has no test file and no task owns one, which
is the blind spot `AGENTS.md` names. The cheapest fix stays inside this task, by mounting the real
`NewSampleHandler` through `NewServer` in `internal/api/server_test.go`, the way T7.1 pins its upload route.

H1 needs a decision the task can make alone. Either add a configuration field for the sample clip, or
widen the candidate search the way `internal/fixtures` already does. The task owns every file involved.

The remediation must re-review all nine findings.
