## H2, the run failure cause

The ledger was a local container, so the Cloud database stayed untouched. The container ran `clickhouse/clickhouse-server:26.8.2.7` on `127.0.0.1:18123`, and `sql/schema.sql` loaded into database `ajilamu`.

```bash
docker run -d --name t81ch -p 127.0.0.1:18123:8123 \
  -e CLICKHOUSE_USER=ajilamu -e CLICKHOUSE_PASSWORD=t81localpass \
  -e CLICKHOUSE_DEFAULT_ACCESS_MANAGEMENT=1 \
  clickhouse/clickhouse-server:26.8.2.7
curl -sS -u ajilamu:t81localpass --data-binary 'CREATE DATABASE IF NOT EXISTS ajilamu' \
  http://127.0.0.1:18123/
docker exec -i t81ch clickhouse-client --user ajilamu --password t81localpass \
  --database ajilamu --multiquery < sql/schema.sql

# run 1, ledger up, sample project, full clip
DUB=b6db43498ff602da6e6876617d0bd71c
SHORT=48d3cd2587bcc2bed14f335239ae66ce
curl -sS -X POST http://127.0.0.1:18090/api/dubs/sample
curl -sS -X POST "http://127.0.0.1:18090/api/dubs/$DUB/run?language=ml"
curl -sS --no-buffer "http://127.0.0.1:18090/api/dubs/$DUB/events"
# terminal done, 59,860,350 nanodollars
# ledger rows: commits 1, actions 1, takes 7, charges 52

# stop the ledger, then run a 13 second speech window
docker stop t81ch
curl -sS -X POST "http://127.0.0.1:18090/api/dubs/$SHORT/run?language=ml"
curl -sS --no-buffer "http://127.0.0.1:18090/api/dubs/$SHORT/events"
# terminal error, "The run could not finish.", 16,446,600 nanodollars

# restart the ledger, then run again
docker start t81ch
curl -sS -X POST "http://127.0.0.1:18090/api/dubs/$SHORT/run?language=ml"
curl -sS --no-buffer "http://127.0.0.1:18090/api/dubs/$SHORT/events"
# terminal done, 16,488,000 nanodollars
# ledger rows: commits 1, actions 1, takes 4, charges 28
```
