## What I did not file

- **The reconnect cost assignment is redundant.** Removing `event.TotalNanodollars = run.cost`
  from `subscribe` survives both my pin and the shipped `TestEventsReconnectKeepsCumulativeCost`.
  `broadcastLocked` sets `run.cost` and `run.last` together, so the two always agree. The line is
  defensive, not a defect. Zeroing the field is caught, which proves the property is guarded.
- **A run registered after `cancelAll` is never cancelled.** `TestR2StartAfterCancelAllStateMachine`
  measures the window. `cancelAll` snapshots the map, then `http.Shutdown` waits for in flight
  handlers, so a start handler can insert a run after the snapshot. Nothing cancels that run and a
  bounded `wait` returns while it still runs. Round one measured shutdown and accepted the bounded
  wait. The window needs a start request to interleave with shutdown. The durable queue retains any
  row the run writes after the flush, so no row is lost. I did not file it.
- **Round one items that still stand.** The charge provider is the Gemini model for every charge.
  Runs serialize across dubs through `pipelineRunner.mu`. Charges for a line with no take file are
  dropped. A partial `newPipelineRunner` build can leak a Gemini client. I re-checked each and
  found no new evidence.
- **The live Gemini and Chirp run.** That run belongs to T8.1. My pins drive the real routes, the
  real registry, the real `assembleRun`, and the real `runPersist` against a stand-in ClickHouse.
