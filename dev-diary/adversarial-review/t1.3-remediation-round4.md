## Contract notes, outside my seam

- **A future task that extends one of the five tables must update the guard in
  the same file.** The preflight now compares columns, default kind and
  expression, engine arguments, keys and constraints as exact sets. A new column,
  default, engine argument or constraint on a guarded table would abort the file
  until the matching `expected_*` list grows. All of those lists live inside
  `sql/schema.sql`, which T1.3 owns.
- **Readers that join takes to charges should name the five identity columns.**
  `dub_id`, `language`, `commit_id`, `segment_index` and `attempt` now lead both
  sorting keys in that order. A join on those five columns reads one contiguous
  run per take, and the round 4 finding 1 repro shows it cannot double across
  two branches.
- **The Cloud native protocol listens on port 9440.** The `.env` port, 8443,
  serves HTTPS. `clickhouse client` needs the native port for `--queries-file`
  mode. The next agent should override the port rather than read it from `.env`.
- **The parallel session's file edits are not mine.** `go.mod`, `go.sum` and
  `dev-diary/PHASE-2-fit-loop.md` show as modified in `git status`, and that work
  belongs to the parallel session. The staging area stays empty. `sql/` holds
  only `schema.sql`, untracked as before.
