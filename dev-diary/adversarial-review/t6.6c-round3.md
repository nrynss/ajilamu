## Additional checks

**The owns expansion holds.** The working tree changed `internal/ledger/workspace.go`,
`internal/ledger/workspace_test.go`, `internal/ledger/workspace_live_test.go` and
`web/src/lib/tabs/DetailsTab.svelte`. Every one sits on the T6.6c owns line. The phase handoff
log carries a `T6.6c owns expansion 2026-09-09` entry that names both new paths and the reason.

**The live test is a real pin.** It failed against the pre-fix statement with units 3 and total
1725100, and passed against the fix with units 2 and total 768000. The seed bills the agent rows
768000 and the other rows 957100, so a fold that leaks past the agent kind reports both numbers
wrong. The probe sits behind `//go:build live` and skips unless `AJILAMU_LIVE_CLICKHOUSE=1`.

**The live test cannot touch a production database by accident.** It reads no `.env` file. The
copy held a `.env` and the probe still failed on the missing `AJILAMU_LIVE_CLICKHOUSE_ADDR`
before any connection. It requires four connection variables by name. Its only delete names the
constant dub `d-t66c-live`. A load into a foreign database runs the schema preflight, which
aborts on an incompatible shape.

**One gap in the live test, not a defect in the shipped statement.** The seed carries agent rows
only, so a statement that dropped `HAVING count() > 0` would still pass the live probe. The fast
shape check pins that clause by substring. I measured the no-agent case directly. `d-r3-nogent`
returned no agent row.

**The chosen keys are unique by construction.** Both charge lists append the array position.
Position is unique inside one each block, so no key can repeat. A reorder changes the keys and
Svelte recreates the nodes, which cannot mis-associate a row with another row's content. The
take keys do not append position, which is finding 1.

**The default suite needs no database.** With the container removed and every ClickHouse
variable unset, `go build ./...`, `go vet ./...` and `go test -count=1 ./internal/... ./cmd/...`
all passed across 14 packages. `npm --prefix web run check` read 183 files with 0 errors and 0
warnings. The live probe skipped with no environment and failed loudly on a partial environment.

**Svelte 5 only.** No `export let`, no `$:`, and no store drove the diff. The two changed key
expressions use the rune template already in the file.
