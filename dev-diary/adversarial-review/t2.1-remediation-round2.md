# T2.1 Remediation Round 2

Round 2 approved T2.1. The live evidence run then failed. The machine ADC at
`/home/nryn/.config/gcloud/application_default_credentials.json` carries type `authorized_user`,
while the hand-rolled token source supported `service_account` key files only. GCE production
needs the metadata server, and the hand-rolled source had no path to it. The repo owner approved
amending the stdlib-first stack with `golang.org/x/oauth2 v0.36.0`. Segmenter and Translator now
accept `oauth2.TokenSource`, and the live probe resolves Application Default Credentials through
`google.FindDefaultCredentials`.
