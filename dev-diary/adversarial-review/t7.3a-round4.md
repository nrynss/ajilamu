## The atomicity decision

The loop writes the record after `RepairLine` returns. A cancel between the take write and the
record write therefore leaves a completed take with no record.
`TestR4TakeWrittenNoRecord` places that state and resumes. `RepairLine` re-renders to the same
path and the production synthesizer refuses to overwrite, so the run aborts. That window is the
pre-existing overwrite collision that rounds 1, 2, and 3 measured and declined. The Done-when
scopes interruption to after a completed take. The patch reduces the collision to that one
window and introduces no new one. The recorded path is sound for the stated acceptance.
