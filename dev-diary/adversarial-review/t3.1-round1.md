### F1 reproduction

Generate the delayed source:

```sh
ffmpeg -v error -f lavfi -i color=black:s=32x32:r=10:d=3 \
  -itsoffset 1 -f lavfi -i sine=frequency=440:sample_rate=44100:duration=1 \
  -map 0:v -map 1:a -ac 2 -c:v libx264 -c:a pcm_s16le delayed.mkv
```

Call `BuildBed("delayed.mkv", "", "delayed-bed.wav")`.
Inspect the source and resulting WAV:

```sh
ffprobe -v error \
  -show_entries stream=codec_type,start_time:format=duration \
  -of json delayed.mkv
ffmpeg -hide_banner -i delayed-bed.wav \
  -af silencedetect=noise=-60dB:d=0.1 -f null -
```

The source video starts at zero. Its audio starts at 1.000000 seconds. Its container duration equals 3.000000 seconds.
The bed contains tone immediately, followed by silence from 1 to 3 seconds.
