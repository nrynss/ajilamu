- Commits: 3 in every trial, the root, the edit and the run commit.
- `version_seq` distribution: `1:1,2:1,3:1` in every trial. No version repeated.
- Head ancestry: 3 commits in every trial.
- Edits on the head chain: 1 in every trial. The run commit was on the head chain in 20 of 20.
- Head timeline: line 1 `0..2950` and line 2 `3500..8000` in 19 trials. Trial 0 made the run
  commit the head, so line 1 read `0..3000`. The edit stayed an ancestor at version 2.
- Control with a 50 ms held commit insert, 5 trials: 0 forks. The reviewer measured 3 of 3
  forks on that shape.
- The reviewer measured 14 of 20 forks on the plain shape before this fix.
