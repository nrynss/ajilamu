### Defect 2, the lockfile

I copied `web/package.json` and `web/package-lock.json` into `/tmp/t76-lock` and ran `npm ci`.
The output was `added 57 packages in 1s` and the exit code was 0. I repeated the run with an
isolated empty cache at `/tmp/t76-npmcache` and got `added 57 packages in 2s`, exit code 0. I
compared all 57 installed `package.json` versions against the lockfile and found zero mismatches.

The two files agree, and `npm ci` proves it. I added `left-pad` to a scratch copy of
`package.json` and `npm ci` failed with exit code 1 and `EUSAGE ... Missing: left-pad@1.3.0 from
lock file`. A drift between the two files therefore stops the install.

The handoff's package count is honest. The `packages` map holds 83 entries, which includes the
root project, so 82 packages exist and 57 install on linux-x64. `npm install --package-lock-only`
in an empty directory produced the same 83 entries and the same 82 versions. That is finding L1's
measurement, and it also confirms the handoff's regeneration note.
