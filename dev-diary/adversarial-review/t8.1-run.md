## Findings

**C. The live ClickHouse Cloud database cannot accept the current writer.** `default.charges_raw` lacks `turn_id` and `call_index`, and its `kind` enum lacks `agent`. Every charge insert returns `Code: 16 NO_SUCH_COLUMN_IN_TABLE`. The run cannot persist, so it ends in an error, the cost ledger stays empty, and the local queue never drains. The same missing column also breaks the workspace read, because `WholePassCharges` selects `turn_id` and `kind='agent'`.

```
server.log: ledger workspace read failed ... Unknown expression or function identifier `turn_id` ...
```

`sql/schema.sql` cannot repair this in place. Its preflight guard aborts before the first `CREATE` when a table already carries another shape, and the file comment names exactly this validation-era table. The database needs to be recreated, or the live `charges_raw` needs the missing columns. This is a deploy gap, not a T8.1 code change.

**H. The readiness probe misreports a healthy ledger as unreachable.** The probe dialer uses a 2 second timeout (`probeDialTimeout`). This host resolves the ClickHouse host in about 6 seconds through the systemd-resolved stub. Go's dial therefore fails with `i/o timeout` and the route answers 503 `unreachable`, while an authenticated query and `/ping` both succeed in under a second.

**H. The run does not finish on a stale schema, and the product reports no cause.** The terminal event carries only "The run could not finish." The underlying ClickHouse error reaches the log only on the shutdown flush, never on the run itself.

**M. The sample run produces only the ducked export.** `assembleRun` calls `Bed.Duck` and exports `dubbed_ducked.mp4` only. No `dubbed_replaced.mp4` exists, so the observations baseline's clean-export tail measurement has no product counterpart for a project with no separate music track.
