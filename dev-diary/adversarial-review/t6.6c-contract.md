# T6.6c contract proposal

## Blocker

T6.6c cannot add a separate agent charge recorder within its owned paths.

`internal/api/server.go` owns `ServerOptions` and wires the agent route. It currently passes
only the editor and logger to `AgentHandler`. The route cannot receive a recorder from
`cmd/ajilamu` without changing that file.

Hiding the recorder inside `EditorAgent` would merge model access with durable storage. That
would not follow the separate recorder seams used by the run and edit routes.

## Required ownership change

Add `internal/api/server.go` and `internal/api/server_test.go` to T6.6c ownership.

The change should add an agent charge recorder to `ServerOptions` and pass it to
`AgentHandler`. `cmd/ajilamu` can then adapt the ledger client onto that seam. A nil recorder
must keep the route available and skip storage.

## Boundary

This record changes no schema, writer, route, or test. T6.6c stops before implementation
because the required route wiring lies outside its ownership.

## Follow-up ownership gap

Implementation exposed one stale behavioral comment in `internal/api/wire.go`.
`AgentResponse` says its total does not change the workspace ledger. T6.6c now records the
response charges and changes that total.

Add `internal/api/wire.go` to T6.6c ownership so the comment can describe the shipped behavior.
No wire field or JSON shape needs to change.
