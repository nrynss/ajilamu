The parser can gain the missing write keywords.

```go
// grantWriteKeyword matches a privilege that breaks the read-only boundary.
// ALTER, DROP, CREATE and TRUNCATE mutate or destroy data, so they fail
// the same way INSERT and ALL do.
var grantWriteKeyword = regexp.MustCompile(`\b(INSERT|ALL|ALTER|CREATE|DROP|TRUNCATE|DELETE|OPTIMIZE|SYSTEM|KILL|UNDROP|MOVE|ATTACH|DETACH)\b`)
```

### 4. The toolText change

The change is required and it is scoped to the probe. A `/tmp` shape test
printed the ADK tool result for `SHOW GRANTS`.

```text
out keys: [output]
out[output] type: map[string]interface {}
inner keys: [result]
result type: string value: {"columns": ["GRANTS FOR mcp_readonly FORMAT Native"], "rows": [["GRANT SELECT ON default.* TO mcp_readonly"]]}
```

ADK returns the MCP structured content as `out["output"]`.
`mcptoolset/tool.go` lines 148 to 152 return `res.StructuredContent` under that
key. `mcp-clickhouse` returns a string, and FastMCP wraps it as
`{"result": "<json string>"}`. `execute_query` in `mcp_server.py` line 1654
serializes `{"columns": ..., "rows": ...}`. `toolText` unwraps `result` and
keeps the string fallback.

I reverted `callTool` to the old `out["output"].(string)` in a `/tmp` copy.
The grant read returned the empty string and the probe failed at line 78 with
`grant set names no SELECT: ""`. So the grant read cannot run without the
unwrap. `toolText` has one caller, `callTool` in the live file, so the change
touches nothing else.

  measured that. A user with a direct SELECT grant and a role that carries
  INSERT shows two rows, and the parser accepts both. That needs the deploy to
  use roles, and the repository documents no role. I treat it as an open limit
  of the deny-list shape rather than a separate finding.
- **The ALL branch is unreachable for the literal string.** `GRANT ALL ON *.*`
  rejects because it names no SELECT. The measured ClickHouse expansion carries
  INSERT, so the branch still fires on real output.
- **The stale handoff sentence.** Line 373 says no container ran. The
  remediation ran one locally. The remediation record carries the transcript.
- **The commit read has no row assertion.** The probe logs the SELECT result
  and never requires a row. Round 1 recorded the same limit. The clause asks
  for a read, not a count.
- **`internal/ledger/takes.go` drops a `ChargeAgent` charge.** No current path
