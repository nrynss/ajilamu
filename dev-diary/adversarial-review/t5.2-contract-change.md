# T5.2 Contract Change Record

## Status

T5.2 can render a typed player and switch dubbed audio without changing the picture source.
It cannot prove the required HTTP range behavior because the fixture is not a public web asset.

## Observation

The existing Vite server returned HTTP 404 for this range request:

```text
Range: bytes=0-63 /testdata/clip.mp4
```

The fixture sits at repository-level `testdata/clip.mp4`, outside Vite's `web/` root.
Vite also returned HTTP 403 for the equivalent development-only `/@fs/` path.

## Required Contract Change

Expose the offline fixture as `web/static/clip.mp4` through a symlink or copy from
`testdata/clip.mp4`. The public asset must preserve the test video bytes.

The later composition or server owner must verify that a request with
`Range: bytes=0-63` receives HTTP 206 and a matching `Content-Range` header.

## Boundary

This record does not create the asset or alter Vite configuration. T5.2 owns only the player
components, so the public fixture belongs to a later asset or server decision.
