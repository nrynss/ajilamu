## What I did not file

- **The five new types have no example payload under `testdata/wire/`.** T1.4's done condition
  says `testdata/` stores an example for each structure. T7.2c owns the new routes and added the
  types without payloads. Its round 1 review recorded that `TimelineView`, `BranchComparison`, and
  `BranchSummary` have no consumer. I report the gap here for the orchestrator. No shipped reader
  or writer exercises those payloads today.
- **`TimelineEntry.VersionSeq` is `uint64` in Go and `number` in TypeScript.** A value above 2^53
  loses precision. T7.2c round 1 measured 1099511627776 and 1099511627777 as exact. A real
  sequence stays far below 2^53. I filed no defect.
- **`BranchSummary.AttributedCostUSD` is money as a decimal string.** The file header says money is
  always an exact nanodollar integer. T7.2c1 chose the decimal string on purpose, and the field doc
  states it. I filed no defect.
- **Go enum fields are `string` while TypeScript uses a union.** `Readiness`, `FitState`,
  `RepairKind`, `ChargeKind`, `CommitAuthor`, `CommitAction`, `EventType`, and `EventStage` follow
  this shape. Round 1 accepted it. The patch did not touch it.
- **Active voice.** My scan found copular clauses and one subordinate passive. For example,
  `Emotion describes how the line is spoken` carries an active main clause. `ReadinessReady means
  the dub is finished and playable` reads clearer than a rewrite. I filed no style defect.
