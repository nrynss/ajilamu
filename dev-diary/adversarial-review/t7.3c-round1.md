### My own cancellation pin

I wrote a fresh pin at `/tmp/t73c-scratch/internal/media/zz_reviewer_pin_test.go`. It installs a
PATH shim named `ffmpeg`. The shim records its pid and then execs the real ffmpeg. The pid file
therefore names the exact child.

| Pin | Measurement |
|---|---|
| Run cancel | Run returned after 1.7ms with `... cancelled: context canceled`. `errors.Is(err, context.Canceled)` held. `syscall.Kill(pid, 0)` then returned ESRCH, so the child exited. |
| Deadline | Run returned an error where `errors.Is(err, context.DeadlineExceeded)` held. |
| WaitDelay | A killed `sh` left `sleep 300` holding the stdout pipe. Wait returned at 5.02s. |
| assemble boundary | Export with a cancelled context returned `probe export video: ffprobe cancelled: context canceled`. errors.Is held. |
| fit boundary | Measure with a cancelled context returned `ffprobe duration ... cancelled: context canceled`. errors.Is held. |

`WaitDelay` is the const `waitDelay` at `internal/media/ffmpeg.go:14`, set to five seconds. It is
bounded. The pin above shows Wait returns at that bound when a grandchild holds the pipe.
