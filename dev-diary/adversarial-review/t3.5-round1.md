## Independent measurements

I own only this review file. The required compute shape exists. I can validate this task alone.

I copied `peaks.go`, `place.go`, `bed.go`, `internal/media`, and `internal/types` into a temporary module.
A small driver called `Peaks` twice per path and printed integer arrays.
Those arrays were the artifact under review. They were not the expected values.

I decoded each file with ffmpeg 9.0.1 to packed `f32le`.
I probed channel count with ffprobe 9.0.1.
I formed frames from that channel count. I took max-abs per frame.
I folded frames into 128 equal-width bins. I scaled each bin to the take peak on 0 to 255.
I used half-away-from-zero rounding. I compared those bins to the driver output.

Every measurement used `PATH=/opt/homebrew/bin:/usr/bin:/bin`.
ffmpeg and ffprobe both report version 9.0.1. Go reports version 1.27.1.
