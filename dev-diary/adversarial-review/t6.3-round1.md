text field, so the page cannot detect this today.

The new take carries an absolute server path. `fixtureTakeSource` cannot resolve it, so
`Play this take` does nothing for the new take. The handoff records this, and T6.5 owns
the asset URL for the ghost take history.

The estimate basis is the newest billed take's full charges. For line 3 that included an
8200 nanodollar translate charge while the panel said no translation runs. The shown
estimate was $0.0023182 and the 201 charged $0.00063. T6.2 set the newest-billed-take
convention, so I file no finding. The number is conservative, not understated.
