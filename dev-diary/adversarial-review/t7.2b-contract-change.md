# T7.2b contract change

## Blocker

T7.2b owns `internal/api/server.go` and `internal/api/server_test.go`. The contract requires two
package-level budget variables, `probeDialTimeout` and `probeResponseBudget`, so tests can shrink
them. `internal/api/server_test.go` is `package api_test` and cannot reach an unexported package
variable.

Moving the file to `package api` fails. `internal/ledger` imports `internal/api`
(`internal/ledger/actions.go:12`, `internal/ledger/peaks.go:7`) and `server_test.go` imports
`internal/ledger` for the durable shutdown flush tests. An internal test package therefore closes
a cycle:

```
import cycle not allowed in test
	imports github.com/nrynss/ajilamu/internal/ledger from server_test.go
	imports github.com/nrynss/ajilamu/internal/api from actions.go
```

Deleting or faking the durable ledger tests would weaken existing coverage, which the task
forbids.

| Where | What | Pin | Mutation |
| --- | --- | --- | --- |
| `internal/api/server_test.go:1` | The file is `package api_test` and cannot name unexported package variables | `go test -count=1 ./internal/api` compiles the external package against the exported API only | Reverting the split leaves `probeResponseBudget` untestable from the external file |
| `internal/api/server.go:172` | `probeDialTimeout` is unexported | A test in `package api_test` cannot assign it | Exporting it changes the package API beyond the route response |
| `internal/api/server.go:180` | `probeResponseBudget` is unexported | A test in `package api_test` cannot assign it | Exporting it changes the package API beyond the route response |
| `internal/ledger/actions.go:12` | The ledger imports the api package | `go list -deps ./internal/api` shows the dependency | Removing the split re-creates the cycle |
| `internal/api/server_test.go:470` | The external test imports the ledger for a real durable flush | `go test -run TestShutdownFlushesDurableLedgerQueue ./internal/api` passes | Dropping the import deletes the flush pin |

## Required ownership change

T7.2b now owns `internal/api/ready_internal_test.go`. It is `package api`, imports only the
standard library plus `internal/config`, and never imports `internal/ledger`, so the api test
binary keeps building. It holds the two budget-shrinking tests:
`TestLedgerReadyReportsWaking` and `TestLedgerReadyReportsUnreachableBeforeBudgetExpires`.

No other task owns `internal/api/ready_internal_test.go`. The path does not appear in any `owns`
line in `dev-diary/PHASE-*.md`. T7.2c owns `internal/api/server.go` and adds a mux line only, so
the new test file cannot conflict.

`go:linkname` and a shorter request-context deadline were both rejected. The first reaches an
unexported variable through unsafe compiler behaviour. The second leaves `probeResponseBudget`
untested.

## Orchestrator contract refinement, round 1

Round 1 recorded a post-connect failure as a contract gap rather than a defect. A TLS client
against a plain HTTP listener reports waking in 0.8ms, so a wrong scheme reports waking forever.
Waking must mean the response budget expired, not that any error followed a connection.

| Condition | HTTP | Body |
|---|---|---|
| TCP connected, the response budget expired with no `/ping` answer | 503 | `{"status":"waking"}` |
| TCP connected, `/ping` failed before answering for any other reason | 503 | `{"status":"unreachable"}` |

A timeout after connect stays waking. A protocol error, a reset, or a scheme mismatch reports
unreachable. Measured: `errors.Is(err, context.DeadlineExceeded)` and `net.Error.Timeout()` are
both false for a TLS handshake against a plain HTTP listener, and true for a context deadline.
