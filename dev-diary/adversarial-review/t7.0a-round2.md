`web/build/index.html` at 1194 bytes, `web/build/_app/`, and `web/build/clip.mp4`.
`du -sh web/build` returned 19M.

web/build/index.html` and exited 0. The same rule covers `web/build/clip.mp4` and the hashed
`_app` assets. The pattern contains a slash, so git anchors it at the repository root. It
cannot catch a stray `build` directory deeper in the tree.

`git add -A -n` listed six paths and none under `web/build`. `git status --short` reports
zero `web/build` entries. `git ls-files web/build` is empty, so the rule hides no tracked
file.

Source files stay trackable. `git check-ignore` on `web/src/routes/+page.svelte`,
`web/package.json`, `web/svelte.config.js`, and `web/static/clip.mp4` printed nothing and
exited 1.
