escapes it. I pinned the escape. I added `type SharedProbe struct` to

```

```

I judge this not a defect. The contract gives T1.4 one shared type file, `internal/api/wire.go`.
T1.4 owns that file. All 17 shared structs live there today. `types.ts` holds exactly 17
interfaces, one per wire struct. The guard's comment states its scope, "derives the shared set
from wire.go". A shared struct in another file requires an author to break the T1.4 seam first.
`internal/api` already holds 14 exported structs outside `wire.go`, such as `RunRequest` and
`Upload`. None is mirrored in `types.ts`. The repository treats those as server-side request
types, not wire types. I state the escape plainly and I still judge it outside the defect.
